# 搞事事 · 用户验收测试计划

> 版本：v0.2（含敌人/粒子/P1 美术）  
> 预计验收时间：15–25 分钟

## 0. 环境准备

### 最低要求（纯客户端）

```bash
cd app
flutter pub get
flutter run -d chrome
```

### 完整联调（可选）

```bash
# 终端1
cd backend && pip install -r requirements.txt && python run.py

# 终端2
cd app && flutter run -d chrome --dart-define=API_BASE_URL=http://localhost:5000
```

### 自动化冒烟（开发者已跑，你可复验）

```bash
cd app && flutter test
cd backend && PYTHONPATH=. pytest -q
python scripts/validate_art_assets.py
```
